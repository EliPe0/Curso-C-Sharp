## Sobre

Esse repositório é onde eu guardo tudo que faço no meu curso de C# na Udemy. Comecei do zero na linguagem e a ideia é usar o repositório como caderno de estudos: cada assunto do curso vira uma pasta, e cada exercício fica salvo pra eu poder consultar depois.

Além das atividades do curso, também resolvo problemas no beecrowd pra treinar lógica de programação.

## Como rodar

**Pré-requisitos:**

- [.NET SDK](https://dotnet.microsoft.com/download)
- Visual Studio ou VS Code

**Passo a passo:**

```bash
# clonar o repositório
git clone https://github.com/EliPe0/curso-c-sharp.git

# entrar na pasta do exercício que quiser testar
cd "curso-c-sharp/Primeiro Projeto"

# rodar o projeto
dotnet run
```

Se preferir, dá pra abrir a pasta direto no Visual Studio e rodar com `F5`.
